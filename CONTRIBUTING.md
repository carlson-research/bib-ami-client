Contributing to bib-ami
=======================

Thank you for your interest in `bib-ami`!

`bib-ami` is developed, maintained, and supported directly by **Carlson Research, LLC**. To ensure a focused development path and maintain strict quality standards across both our open-source package and commercial cloud integrations, **we are not accepting external code Pull Requests (PRs) at this time.**

However, feedback and bug reports from the research community are always welcome and greatly appreciated!

How You Can Help
----------------

### 1. Reporting Bugs
If you encounter a bug, edge case, or parsing error while using `bib-ami`, please open an issue on our GitHub repository. Detailed bug reports help us improve the tool for everyone.

To help us fix the issue quickly, please include:
- **A clear, descriptive title.**
- **Steps to reproduce the issue** (including example `.bib` entries or code snippets if possible).
- **Expected vs. actual behavior** (along with any error messages or stack traces).
- **Environment details:** Operating system, Python version, and `bib-ami` version.

### 2. Feature Requests & Feedback
Have an idea for a new feature, a metadata field improvement, or an workflow enhancement? Please open a GitHub Issue tagged as a Feature Request. We review all feedback when planning future releases of both `bib-ami` and our managed enterprise APIs.

Pull Requests & Code Contributions
----------------------------------

Please note that any unsolicited Pull Requests will be closed without review. We ask that developers refrain from submitting code contributions so that we can focus our engineering efforts on core maintenance, CrossRef API integrations, and cloud infrastructure.

Need Enterprise Scale or High Throughput?
------------------------------------------

If your organization requires high-throughput processing, multi-node graph harmonization, or dedicated SLAs, please check out the hosted **bib-ami Cloud Service** available on AWS Marketplace and Google Cloud Marketplace, or contact **Carlson Research, LLC**.

Thank you for using `bib-ami` and helping us keep academic literature verified and clean!
