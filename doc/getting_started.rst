Getting Started
===============

This guide covers installing ``bib-ami``, launching the interactive web application, and running basic terminal lookups.

Installation
------------

Install ``bib-ami`` using ``pip``:

.. code-block:: bash

   pip install bib-ami

*Requires Python 3.11 or higher.*

Launching the Web Interface
---------------------------

To open the interactive web interface in your default browser:

.. code-block:: bash

   bib-ami launch

Command-Line Lookup
-------------------

Perform quick citation lookups directly from your terminal:

.. code-block:: bash

   bib-ami lookup 10.1038/nature12345
